The controller will automatically:
  1. Discover Vault pods with labels: app.kubernetes.io/name=vault, component=server
  2. Initialize uninitialized Vault instances
  3. Store root tokens and unseal keys as Kubernetes secrets
  4. Unseal sealed Vault instances

Managed Kubernetes secrets (in {{ .Values.controller.vaultNamespace }} namespace):
  - vault-root-token:  Contains the Vault root token
  - vault-unseal-keys: Contains the unseal keys (key1..key5)

To check controller logs:
  kubectl logs -f deployment/{{ include "vault-auto-unseal.fullname" . }} -n {{ .Release.Namespace }}
